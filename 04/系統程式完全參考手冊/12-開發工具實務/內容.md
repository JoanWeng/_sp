## 12.1 GCC 編譯器

### 12.1.1 GCC 的完整工具鏈

GCC（GNU Compiler Collection）不只是一個 C 編譯器，而是一套完整的編譯工具鏈：

```bash
# 觀察 GCC 實際呼叫了哪些工具
gcc -v hello.c -o hello

# 輸出（簡化）：
# cc1 hello.c -o /tmp/ccXXX.s   ← C 前置處理 + 編譯
# as /tmp/ccXXX.s -o /tmp/ccXXX.o  ← GNU 組譯器
# ld /tmp/ccXXX.o -lc -o hello  ← GNU 連結器
```

### 12.1.2 逐步編譯

```bash
# ── 步驟一：前置處理（Preprocessing）──────────────────────
gcc -E hello.c -o hello.i
# 展開 #include、#define、條件編譯
# 輸出純 C 程式碼（含行號標記 # N "filename"）
wc -l hello.i         # 通常比原始碼大很多（展開了標頭檔）

# ── 步驟二：編譯（Compilation）────────────────────────────
gcc -S hello.i -o hello.s     # 或直接從 .c
gcc -S hello.c -o hello.s
# 輸出 AT&T 語法的 x86-64 組合語言
cat hello.s

# ── 步驟三：組譯（Assembly）───────────────────────────────
gcc -c hello.s -o hello.o     # 或直接從 .c
gcc -c hello.c -o hello.o
# 輸出可重定位目的碼（ELF .o）
file hello.o           # ELF 64-bit LSB relocatable...

# ── 步驟四：連結（Linking）────────────────────────────────
gcc hello.o -o hello
./hello
```

### 12.1.3 常用編譯選項

```bash
# ── 最佳化等級 ────────────────────────────────────────────
-O0          # 無最佳化（預設，最易除錯）
-O1          # 基本最佳化
-O2          # 建議的生產環境設定
-O3          # 激進最佳化（含自動向量化）
-Os          # 最佳化程式碼大小
-Og          # 最佳化同時保持除錯友善

# ── 除錯資訊 ──────────────────────────────────────────────
-g           # 產生 DWARF 除錯資訊（gdb 使用）
-g3          # 最完整的除錯資訊（含巨集資訊）
-ggdb        # 針對 GDB 最佳化的除錯資訊

# ── 警告設定 ──────────────────────────────────────────────
-Wall        # 開啟大多數警告
-Wextra      # 開啟額外警告
-Werror      # 將所有警告視為錯誤
-Wshadow     # 警告變數遮蔽
-Wformat=2   # 格式字串安全性警告

# ── 安全強化 ──────────────────────────────────────────────
-fstack-protector-strong   # Stack Canary 保護
-D_FORTIFY_SOURCE=2        # 緩衝區溢位偵測
-pie -fPIE                 # 位置無關可執行檔（配合 ASLR）
-z relro -z now            # 唯讀重定位區段

# ── 標準與特性 ────────────────────────────────────────────
-std=c11     # C11 標準
-std=c99     # C99 標準
-std=gnu17   # GNU 擴展的 C17（GCC 預設）
-pedantic    # 嚴格遵守標準（不允許 GNU 擴展）

# ── 連結選項 ──────────────────────────────────────────────
-L/path      # 新增程式庫搜尋路徑
-lname       # 連結 libname.so 或 libname.a
-static      # 強制靜態連結
-shared      # 產生共享程式庫（.so）
-fPIC        # 位置無關程式碼（共享程式庫必須）

# ── 輸出控制 ──────────────────────────────────────────────
-o output    # 指定輸出檔名
-v           # 顯示詳細執行步驟
-###         # 顯示將執行的指令但不實際執行
-save-temps  # 保留中間檔案（.i .s .o）
```

### 12.1.4 觀察最佳化的效果

```bash
# 比較不同最佳化等級的組語輸出
cat > example.c << 'EOF'
int sum(int n) {
    int s = 0;
    for (int i = 1; i <= n; i++)
        s += i;
    return s;
}
EOF

gcc -O0 -S example.c -o example_O0.s
gcc -O2 -S example.c -o example_O2.s

# O2 可能會用高斯公式 s = n*(n+1)/2 來取代迴圈
cat example_O2.s
```

## 12.2 NASM 組譯器

### 12.2.1 基本使用

```bash
# 組譯為 64-bit ELF 目的碼
nasm -f elf64 hello.asm -o hello.o

# 組譯為 32-bit ELF
nasm -f elf32 hello.asm -o hello.o

# 組譯為 Windows 64-bit COFF
nasm -f win64 hello.asm -o hello.obj

# 組譯為平坦二進位（bootloader / 韌體）
nasm -f bin hello.asm -o hello.bin

# 產生列表檔（含位址和機器碼）
nasm -f elf64 -l hello.lst hello.asm -o hello.o
cat hello.lst
```

### 12.2.2 列表檔（Listing File）

```
nasm -f elf64 -l output.lst hello.asm -o hello.o

列表檔格式：
行號  位址      機器碼              原始碼
  1              -                   ; Hello World
  2              -          section .data
  3  00000000  48 65 6C 6C 6F...    msg DB "Hello, World!", 0xa
  4  0000000E  =E                   msg_len EQU $ - msg
  5              -          section .text
  6              -          global _start
  7              -          _start:
  8  00000000  B8 01000000          mov rax, 1
  9  00000005  BF 01000000          mov rdi, 1
```

### 12.2.3 NASM 的除錯輸出

```bash
# 顯示展開後的巨集（除錯巨集問題）
nasm -E hello.asm          # 只做前置處理（展開 %include、巨集）

# 更詳細的錯誤資訊
nasm -f elf64 -w+all hello.asm -o hello.o   # 開啟所有警告

# 產生除錯符號（供 gdb 使用）
nasm -f elf64 -g -F dwarf hello.asm -o hello.o
```

## 12.3 GDB 偵錯器

### 12.3.1 基本工作流程

```bash
# 編譯時加入除錯資訊
gcc -g -O0 hello.c -o hello
nasm -f elf64 -g -F dwarf hello.asm -o hello.o
ld hello.o -o hello

# 啟動 GDB
gdb ./hello
gdb -tui ./hello   # 文字使用者介面（分割視窗顯示原始碼）

# 啟動後直接執行到特定函式
gdb -ex "break main" -ex "run" ./hello
```

### 12.3.2 常用 GDB 指令

```gdb
(gdb) help                    -- 顯示幫助

── 中斷點（Breakpoint）────────────────────────────────
(gdb) break main              -- 在 main 函式設中斷點
(gdb) break 42                -- 在第 42 行設中斷點
(gdb) break hello.c:25        -- 在 hello.c 第 25 行
(gdb) break *0x401234         -- 在位址設中斷點（組語用）
(gdb) info breakpoints        -- 列出所有中斷點
(gdb) delete 2                -- 刪除中斷點 2
(gdb) disable 1               -- 暫時停用中斷點 1
(gdb) watch x                 -- 監視點：x 的值改變時停止

── 執行控制 ─────────────────────────────────────────────
(gdb) run                     -- 開始執行
(gdb) run arg1 arg2           -- 帶引數執行
(gdb) continue    (c)         -- 繼續到下一個中斷點
(gdb) step        (s)         -- 單步執行（進入函式）
(gdb) next        (n)         -- 單步執行（不進入函式）
(gdb) finish                  -- 執行到目前函式結束
(gdb) until 50                -- 執行到第 50 行
(gdb) stepi       (si)        -- 單步執行一條機器指令
(gdb) nexti       (ni)        -- 單步機器指令（不進入函式）

── 檢視程式狀態 ────────────────────────────────────────
(gdb) print x                 -- 印出變數 x 的值
(gdb) print/x x               -- 以十六進位印出
(gdb) print/d x               -- 以十進位印出
(gdb) print *ptr              -- 印出指標指向的值
(gdb) print arr[3]            -- 印出陣列元素
(gdb) display x               -- 每次停下時自動印出 x
(gdb) info registers          -- 顯示所有暫存器
(gdb) info registers rax rbx  -- 只顯示指定暫存器
(gdb) print $rax              -- 印出暫存器（GDB 用 $ 前綴）
(gdb) x/10x $rsp              -- 以十六進位傾印 RSP 往後 10 個 word
(gdb) x/10i $rip              -- 反組譯 RIP 往後 10 條指令
(gdb) x/s 0x601000            -- 以字串格式顯示記憶體

── 堆疊 ─────────────────────────────────────────────────
(gdb) backtrace   (bt)        -- 顯示呼叫堆疊
(gdb) frame 2                 -- 切換到堆疊框架 2
(gdb) info locals             -- 顯示目前框架的區域變數
(gdb) info args               -- 顯示目前框架的函式引數

── 反組譯 ───────────────────────────────────────────────
(gdb) disassemble             -- 反組譯目前函式
(gdb) disassemble main        -- 反組譯 main
(gdb) disassemble /m main     -- 混合顯示原始碼與組語
(gdb) set disassembly-flavor intel  -- 切換為 Intel 語法
(gdb) layout asm              -- TUI 模式：顯示組語視窗
(gdb) layout regs             -- TUI 模式：顯示暫存器視窗
```

### 12.3.3 記憶體檢視格式

```gdb
(gdb) x/[count][format][size] [address]

format：
  x = hex         d = decimal     u = unsigned decimal
  o = octal       t = binary      f = float
  s = string（null 結尾）         i = instruction（反組譯）

size：
  b = byte（1B）  h = half（2B）  w = word（4B）  g = giant（8B）

範例：
(gdb) x/16xb $rsp          -- 以 byte 十六進位顯示 RSP 後 16 bytes
(gdb) x/4gx $rsp           -- 以 8-byte（giant）十六進位顯示 4 個
(gdb) x/10i $rip           -- 反組譯 RIP 後 10 條指令
(gdb) x/s 0x601000         -- 顯示位址 0x601000 的字串
```

### 12.3.4 GDB Script 自動化

```gdb
# 建立 .gdbinit 或使用 -x 選項載入腳本
# 範例：gdb_helper.txt

set disassembly-flavor intel
set pagination off
break _start
run
layout split        # 同時顯示原始碼和暫存器
info registers
```

```bash
gdb -x gdb_helper.txt ./hello
```

## 12.4 Make 建構系統

### 12.4.1 Makefile 基本結構

```makefile
# 基本規則格式：
# 目標: 依賴
#     命令（必須以 Tab 開頭！）

# 變數定義
CC      = gcc
NASM    = nasm
CFLAGS  = -Wall -Wextra -O2 -g
NASMFLAGS = -f elf64 -g -F dwarf

# 預設目標（第一個目標）
all: hello

# 編譯規則
hello: main.o util.o
    $(CC) $(CFLAGS) $^ -o $@

main.o: main.c main.h
    $(CC) $(CFLAGS) -c $< -o $@

util.o: util.asm
    $(NASM) $(NASMFLAGS) $< -o $@

# 清理
clean:
    rm -f *.o hello

# 偽目標（不是真正的檔案）
.PHONY: all clean
```

### 12.4.2 自動變數

```makefile
$@    # 目標檔名
$<    # 第一個依賴檔名
$^    # 所有依賴檔名（以空白分隔）
$*    # 模式匹配的詞幹（Stem）

# 模式規則（Pattern Rule）
%.o: %.c
    $(CC) $(CFLAGS) -c $< -o $@

%.o: %.asm
    $(NASM) $(NASMFLAGS) $< -o $@
```

### 12.4.3 進階 Makefile 範例

```makefile
CC       = gcc
NASM     = nasm
CFLAGS   = -Wall -Wextra -std=c11 -O2 -g
LDFLAGS  =
NASMFLAGS = -f elf64 -g -F dwarf

# 自動找出所有 .c 和 .asm 原始檔
C_SRCS   := $(wildcard src/*.c)
ASM_SRCS := $(wildcard src/*.asm)

# 對應的目的檔
C_OBJS   := $(C_SRCS:src/%.c=build/%.o)
ASM_OBJS := $(ASM_SRCS:src/%.asm=build/%.o)
OBJS     := $(C_OBJS) $(ASM_OBJS)

TARGET   = bin/program

all: $(TARGET)

# 連結
$(TARGET): $(OBJS) | bin
    $(CC) $(LDFLAGS) $^ -o $@
    @echo "✓ 建置完成：$@"

# C 檔編譯（自動建立 build/ 目錄）
build/%.o: src/%.c | build
    $(CC) $(CFLAGS) -c $< -o $@

# ASM 檔組譯
build/%.o: src/%.asm | build
    $(NASM) $(NASMFLAGS) $< -o $@

# 建立目錄
build:
    mkdir -p build

bin:
    mkdir -p bin

# 自動產生相依性（#include 追蹤）
-include $(C_OBJS:.o=.d)
build/%.d: src/%.c | build
    $(CC) -MM -MT build/$*.o $< > $@

clean:
    rm -rf build bin

run: $(TARGET)
    ./$(TARGET)

.PHONY: all clean run
```

### 12.4.4 常用 Make 指令

```bash
make              # 建置預設目標（第一個目標）
make all          # 建置 all 目標
make clean        # 清理
make -j4          # 平行建置（4 個執行緒）
make -j$(nproc)   # 使用所有 CPU 核心
make -n           # 乾跑（顯示將執行的指令但不執行）
make -B           # 強制重建所有目標
make V=1          # 顯示詳細指令（部分 Makefile 支援）
make CFLAGS="-O0 -g"  # 覆蓋變數
```

## 12.5 二進位分析工具

### 12.5.1 file — 識別檔案類型

```bash
file hello               # ELF 64-bit LSB pie executable...
file hello.o             # ELF 64-bit LSB relocatable...
file libfoo.so           # ELF 64-bit LSB shared object...
file hello.a             # current ar archive
file /bin/bash           # ELF 64-bit LSB pie executable...
```

### 12.5.2 size — 各區段大小

```bash
size hello
#    text    data     bss     dec     hex filename
#    1234      64      16    1314     522 hello

size -A hello    # 顯示所有 section 的大小
```

### 12.5.3 objdump — 多功能分析

```bash
# 反組譯
objdump -d hello                    # 反組譯 .text
objdump -d -M intel hello           # Intel 語法
objdump -S hello                    # 混合原始碼與組語（需要 -g）
objdump -D hello                    # 反組譯所有 section

# 符號與重定位
objdump -t hello                    # 符號表
objdump -r hello.o                  # 重定位表
objdump -R hello                    # 動態重定位（.so / exe）

# Section 資訊
objdump -s hello                    # 以 hex+ASCII 顯示所有 section
objdump -s -j .data hello           # 只顯示 .data section
objdump -h hello                    # Section headers

# 解碼特定位址
objdump -d --start-address=0x401000 --stop-address=0x401050 hello
```

### 12.5.4 readelf — ELF 詳細分析

```bash
readelf -h hello         # ELF Header
readelf -S hello         # Section Header Table
readelf -l hello         # Program Header Table（Segment）
readelf -s hello         # 符號表
readelf -s --wide hello  # 完整顯示長符號名
readelf -r hello         # 重定位表
readelf -d hello         # Dynamic Section（.so 依賴等）
readelf -n hello         # Note Section
readelf -a hello         # 顯示所有資訊
readelf -x .data hello   # 以 hex 顯示 .data section
readelf -p .rodata hello # 以字串顯示 .rodata section
```

### 12.5.5 nm — 符號表

```bash
nm hello                 # 所有符號（位址 類型 名稱）
nm -u hello              # 未定義符號（UNDEF）
nm -g hello              # 全域符號
nm -n hello              # 依位址排序
nm -D hello              # 動態符號表（等同 --dynamic）
nm -C hello              # C++ 符號解修飾（Demangling）
nm --defined-only hello  # 只顯示有定義的符號

# 符號類型說明：
# T = .text（全域）  t = .text（局部）
# D = .data（全域）  d = .data（局部）
# B = .bss（全域）   b = .bss（局部）
# U = UNDEF（未定義，需連結器解析）
# R = .rodata        C = COMMON
```

### 12.5.6 strace — 系統呼叫追蹤

```bash
strace ./hello                    # 追蹤所有系統呼叫
strace -e trace=read,write ./hello  # 只追蹤 read/write
strace -e trace=file ./hello     # 所有檔案相關的系統呼叫
strace -c ./hello                 # 統計每個系統呼叫的次數與時間
strace -o log.txt ./hello         # 輸出到檔案
strace -f ./hello                 # 追蹤 fork() 建立的子行程
strace -p 1234                    # 追蹤已執行的行程（PID 1234）

# 典型輸出：
# execve("./hello", ["./hello"], 0x... /* 20 vars */) = 0
# write(1, "Hello, World!\n", 14)  = 14
# exit_group(0)                     = ?
```

### 12.5.7 ldd — 動態程式庫相依

```bash
ldd hello                         # 列出所有 .so 相依
ldd -v hello                      # 詳細資訊（含版本）
ldd /lib/x86_64-linux-gnu/libc.so.6  # libc 本身的相依

# 典型輸出：
#   linux-vdso.so.1 (0x00007ffd...)
#   libc.so.6 => /lib/x86_64-linux-gnu/libc.so.6 (0x00007f...)
#   /lib64/ld-linux-x86-64.so.2 (0x00007f...)
```

### 12.5.8 hexdump / xxd — 十六進位傾印

```bash
hexdump -C hello.o | head -20     # 十六進位 + ASCII
xxd hello.o | head -20            # 另一種格式
xxd -l 64 hello.o                 # 只看前 64 bytes（ELF Header）

# 搜尋特定 bytes
xxd hello.o | grep "7f 45 4c 46"  # 搜尋 ELF 魔術數字
```

## 12.6 效能分析工具

### 12.6.1 perf — Linux 效能計數器

```bash
# 基本效能分析
perf stat ./hello                 # 統計執行時的硬體計數器

# 典型輸出：
#  Performance counter stats for './hello':
#    0.542138 ms  task-clock                 # 使用了 0.54ms CPU 時間
#     1,234        context-switches
#     123,456      cycles
#     234,567      instructions              # IPC = instructions/cycles
#      56,789      branch-misses

# 取樣剖析（找出熱點函式）
perf record ./slow_program        # 執行並記錄取樣
perf report                       # 互動式檢視結果

# 函式層級的統計
perf stat -d ./hello              # 含 cache miss 等詳細資訊

# 追蹤系統呼叫（類 strace）
perf trace ./hello
```

### 12.6.2 gprof — 函式呼叫剖析

```bash
# 步驟一：編譯時加入剖析旗標
gcc -pg -O2 hello.c -o hello

# 步驟二：執行程式（自動產生 gmon.out）
./hello

# 步驟三：分析剖析資料
gprof hello gmon.out | head -40

# 輸出包含：
# - Flat profile：每個函式耗用的時間
# - Call graph：呼叫關係與時間分佈
```

### 12.6.3 Valgrind — 記憶體分析

```bash
# 偵測記憶體錯誤（越界存取、use-after-free、記憶體洩漏）
valgrind ./hello

# 完整記憶體錯誤報告
valgrind --leak-check=full ./hello

# 快取行為分析
valgrind --tool=cachegrind ./hello
cg_annotate cachegrind.out.* | head -40

# 呼叫圖剖析
valgrind --tool=callgrind ./hello
callgrind_annotate callgrind.out.* | head -40
kcachegrind callgrind.out.*        # 圖形介面查看
```

### 12.6.4 AddressSanitizer（ASan）

比 Valgrind 更快的記憶體錯誤偵測工具（GCC/Clang 內建）：

```bash
# 編譯時加入 ASan
gcc -fsanitize=address -g -O1 hello.c -o hello
./hello

# ASan 可偵測：
# - Heap buffer overflow（堆積越界）
# - Stack buffer overflow（堆疊越界）
# - Use after free
# - Use after return
# - Double free
# - Memory leaks（需加 -fsanitize=leak）

# 同時使用多個 sanitizer
gcc -fsanitize=address,undefined -g hello.c -o hello
# UBSan 可偵測未定義行為（整數溢位、NULL 解參考等）
```

## 12.7 典型開發流程整合

### 12.7.1 完整的專案 Makefile

```makefile
# 完整的 C + ASM 混合專案建構腳本

PROJECT  = myapp
VERSION  = 1.0

CC       = gcc
NASM     = nasm
LD       = gcc

CFLAGS   = -Wall -Wextra -std=c11 -O2
DBGFLAGS = -g3 -O0 -fsanitize=address,undefined
NASMFLAGS = -f elf64
LDFLAGS  =

SRC_DIR  = src
OBJ_DIR  = build
BIN_DIR  = bin

C_SRCS   := $(wildcard $(SRC_DIR)/*.c)
ASM_SRCS := $(wildcard $(SRC_DIR)/*.asm)
C_OBJS   := $(patsubst $(SRC_DIR)/%.c,  $(OBJ_DIR)/%.o, $(C_SRCS))
ASM_OBJS := $(patsubst $(SRC_DIR)/%.asm,$(OBJ_DIR)/%.o, $(ASM_SRCS))
OBJS     := $(C_OBJS) $(ASM_OBJS)
TARGET   := $(BIN_DIR)/$(PROJECT)

# ── 主要目標 ────────────────────────────────────────────────
all: $(TARGET)

$(TARGET): $(OBJS) | $(BIN_DIR)
	$(LD) $(LDFLAGS) $^ -o $@
	@echo "  ✓ 建置成功：$@ (v$(VERSION))"

# ── 除錯版本 ────────────────────────────────────────────────
debug: CFLAGS = $(DBGFLAGS)
debug: NASMFLAGS += -g -F dwarf
debug: clean $(TARGET)
	@echo "  ✓ 除錯版本建置完成"

# ── 編譯規則 ────────────────────────────────────────────────
$(OBJ_DIR)/%.o: $(SRC_DIR)/%.c | $(OBJ_DIR)
	@echo "  CC  $<"
	$(CC) $(CFLAGS) -c $< -o $@

$(OBJ_DIR)/%.o: $(SRC_DIR)/%.asm | $(OBJ_DIR)
	@echo "  ASM $<"
	$(NASM) $(NASMFLAGS) $< -o $@

# ── 目錄建立 ────────────────────────────────────────────────
$(OBJ_DIR) $(BIN_DIR):
	mkdir -p $@

# ── 分析目標 ────────────────────────────────────────────────
disasm: $(TARGET)
	objdump -d -M intel $< | less

symbols: $(TARGET)
	nm -n --defined-only $<

deps: $(TARGET)
	ldd $<

memcheck: debug
	valgrind --leak-check=full $(TARGET)

# ── 清理 ────────────────────────────────────────────────────
clean:
	rm -rf $(OBJ_DIR) $(BIN_DIR)

.PHONY: all debug disasm symbols deps memcheck clean
```

### 12.7.2 GDB 快速除錯流程

```bash
# 1. 除錯版本編譯
make debug

# 2. 啟動 GDB（TUI 模式）
gdb -tui ./bin/myapp

# 3. 常用初始設定
(gdb) set disassembly-flavor intel
(gdb) set print pretty on
(gdb) break main
(gdb) run

# 4. 出現 Segmentation Fault 時
(gdb) run
# Program received signal SIGSEGV...
(gdb) backtrace        # 查看呼叫堆疊
(gdb) frame 0          # 切換到崩潰的框架
(gdb) info locals      # 查看局部變數
(gdb) print *ptr       # 若 ptr 為 NULL 這裡會出錯
(gdb) x/20x $rsp       # 查看堆疊內容
```

## 12.8 本章小結

**GCC 工具鏈：**
- 四個階段：前置處理（-E）→ 編譯（-S）→ 組譯（-c）→ 連結
- -O0 除錯，-O2 生產，-g 加除錯資訊，-Wall 開啟警告
- -fsanitize=address 快速記憶體錯誤偵測

**NASM：**
- `-f elf64` 產生 64-bit Linux 目的碼
- `-g -F dwarf` 加入 GDB 可識別的除錯資訊
- `-l listing.lst` 產生含位址與機器碼的列表檔

**GDB：**
- `break` / `run` / `next` / `step` / `continue` 是最常用的五個指令
- `x/Nfz addr` 靈活的記憶體檢視格式
- `set disassembly-flavor intel` 切換為 Intel 語法
- `-tui` 模式同時顯示原始碼與暫存器

**Make：**
- 目標、依賴、命令（Tab 縮排）三元結構
- `$@`（目標）、`$<`（第一個依賴）、`$^`（所有依賴）自動變數
- `%.o: %.c` 模式規則避免重複撰寫
- `-j$(nproc)` 平行建置加速

**二進位分析：**
- `readelf` / `objdump` 分析 ELF 結構
- `nm` 查看符號表，`-u` 只看未定義符號
- `strace` 追蹤系統呼叫，`ldd` 查看 .so 依賴
- `perf stat` 快速硬體效能計數，`valgrind` 完整記憶體分析
