# EmoLang 使用指南

## GUI 功能總覽

### 1. 檔案操作
| 按鈕 | 功能 |
|------|------|
| 📄 新建 | 清空編輯器，開始新檔案 |
| 📂 開啟 | 開啟 `.emo` 檔案 |
| 💾 儲存 | 另存新檔 |

### 2. 執行程式
- **▶ 執行**：執行編輯器中的 EmoLang 程式碼，結果顯示在右側輸出區
- **🗑️ 清除**：清空輸出區
- 若程式中有 `📥`（INPUT），會自動彈出輸入對話框

### 3. 語意突顯
編輯器會自動將不同 token 以不同顏色標示：
- 關鍵字（📦 🔢 🎈 等）：**藍色**
- 字串常數：**橘色**
- 數值常數：**綠色**
- 函式定義：**黃色**
- 註解：**灰色**

### 4. 語法錯誤標記
若程式碼有語法錯誤，錯誤位置會以**紅底紅字**標記，下方狀態列會顯示錯誤訊息。

### 5. 懸浮提示 (Hover)
滑鼠移到 token 上停留 **0.4 秒**，會彈出提示框顯示：
- 變數的類型與數值
- 函式的簽名
- 保留字的說明

移過 token 時該 token 會加底線。

### 6. 大綱面板 (Outline)
左側大綱面板自動顯示程式中的：
- 📦 變數宣告（LET）
- 🛠️ 函式定義（FUNC_DEF）
- 🏗️ 結構體定義（STRUCT_DEF）

**點擊大綱項目**可直接跳轉到對應程式行。

### 7. 跳至定義 (F12 / Ctrl+G)
將游標放在變數或函式名稱上，按下：
- **F12** 或 **Ctrl+G**

編輯器會跳到該符號的定義位置。若游標不在識別字上，或找不到定義，狀態列會顯示提示。

### 8. 程式碼摺疊 (Code Folding)
| 操作 | 說明 |
|------|------|
| 工具列「📂 摺疊」 | 摺疊所有 `👇 ... 👆` 區塊 |
| 工具列「📂 展開」 | 展開所有已摺疊區塊 |
| 點擊 `… 👆 (N lines) [#XXXX]` 綠色標記 | 展開單一區塊 |

摺疊後該行會顯示為綠色 `  … 👆 (N lines) [#XXXX]  `，點擊即可展開。
僅支援頂層區塊摺疊（不摺疊巢狀區塊），避免混亂。

### 9. 重新命名 (F2)
1. 將游標放在變數或函式名稱上
2. 按下 **F2**
3. 彈出對話框輸入新名稱
4. 編輯器中所有同名符號會自動替換

若游標不在識別字上，狀態列會提示「F2: 游標不在識別字上」。

### 10. 尋找參照 (Ctrl+Shift+F)
1. 將游標放在變數或函式名稱上
2. 按下 **Ctrl+Shift+F**
3. 彈出視窗列出所有參照位置 (`line N:M  name`)
4. 點選任一項目即可跳轉到該位置

若無任何參照，狀態列會顯示沒有參照。

### 11. 表情符號面板
- 按工具列 **🔣** 按鈕切換顯示/隱藏
- 將 EmoLang token 分組排列：
  - 變數宣告：📦 📝 🔢 🎈 🚦 🟰
  - 流程控制：📢 📥 🤔 🤷 🔁 🎡 🚧
  - 區塊/函式：👇 👆 🛠️ 🔙 🏗️ 🆕 ➡️
  - 運算子：➕ ➖ ✖️ ➗ ✂️ 🤝 📈 📉
  - 邏輯/指標：🔗 🔀 🙅 📍 🎯 📌 📚
  - 資料結構：📋 📖 🛒 📏 🟢 🔴
- 滑鼠移到按鈕上會顯示對應的 EmoLang 說明
- 點擊即可插入到編輯器

### 12. Ghost Text 自動補齊
編輯時會自動顯示灰色預測文字：
- **行內補齊**：輸入變數/關鍵字時，若 Completion Engine 預測到完整名稱會顯示 ghost text
- **下行補齊**：若當前行為空，且上兩行程式碼重複出現過，會建議下一行
- 按 **Tab** 接受 ghost text 補齊
- 按 **Tab** 接受下一行補齊

### 13. 狀態列
編輯器下方有兩行狀態列：
- **第一行**：顯示語法錯誤狀態（✔ 無語法錯誤 / ⚠ 錯誤訊息）
- **第二行**：顯示操作結果提示（定義跳轉、摺疊/展開數、參照數、重新命名結果等）

### 14. 復原 / 重做
- 工具列「↩ 復原」與「↪ 重做」按鈕支援無限層級復原
- 快捷鍵：**Ctrl+Z** 復原、**Ctrl+Y** 重做
- 復原/重做後自動更新語法突顯與行號

### 15. 錯誤診斷面板
- 工具列「⚠ 錯誤」按鈕開啟診斷結果視窗
- 列出所有語法錯誤（最多 5 個）
- 點擊任一錯誤即可跳轉到對應行號
- 錯誤行在編輯器以紅底紅字標記

### 16. 行號
- 編輯器左側顯示行號
- 行號會隨摺疊／展開自動更新

## 快捷鍵總表

| 快捷鍵 | 功能 |
|--------|------|
| Ctrl+N | 開新檔案 |
| Ctrl+O | 開啟檔案 |
| Ctrl+S | 存檔 |
| Ctrl+F | 尋找 |
| Ctrl+Z | 復原 |
| Ctrl+Y | 重做 |
| F12 / Ctrl+G | 跳至定義 |
| F2 | 重新命名符號 |
| Ctrl+Shift+F | 尋找所有參照 |
| Tab | 接受 ghost text 補齊 |
| Tab (行首) | 接受下一行補齊 |

---

## 注意事項
- 語法高亮顏色請參閱程式碼中的 `ColorTheme` 類別
- 若要新增 Emoji 對應，請編輯 `EMOJI_NAMES` 字典與 Emoji 按鈕列
