# EmoLang Emoji 指令一覽

## 變數宣告

| Emoji | 關鍵字 | 說明 | 語法 |
|-------|--------|------|------|
| 📦 | LET | 通用變數（void\*，可裝載任何型態） | `📦 名稱 🟰 值` |
| 🔢 | INT | 整數變數（int） | `🔢 名稱 🟰 數值` |
| 🎈 | FLOAT | 小數變數（float） | `🎈 名稱 🟰 小數` |
| 📝 | STR | 字串變數（str） | `📝 名稱 🟰 "字串"` |
| 🚦 | BOOL | 布林變數（bool） | `🚦 名稱 🟰 🟢` |

## 運算子

| Emoji | 關鍵字 | 說明 | 語法 |
|-------|--------|------|------|
| 🟰 | ASSIGN | 賦值（=） | `名稱 🟰 值` |
| ➕ | PLUS | 加法或字串拼接 | `a ➕ b` |
| ➖ | MINUS | 減法 | `a ➖ b` |
| ✖️ | MUL | 乘法 | `a ✖️ b` |
| ➗ | DIV | 除法 | `a ➗ b` |
| ✂️ | MOD | 取餘數 | `a ✂️ b` |
| 🤝 | EQ | 等於比較（==） | `a 🤝 b` |
| 📈 | GT | 大於（>） | `a 📈 b` |
| 📉 | LT | 小於（<） | `a 📉 b` |
| 🔗 | AND | 邏輯 AND（&&） | `條件A 🔗 條件B` |
| 🔀 | OR | 邏輯 OR（\|\|） | `條件A 🔀 條件B` |
| 🙅 | NOT | 邏輯 NOT（!） | `🙅 條件` |

## 流程控制

| Emoji | 關鍵字 | 說明 | 語法 |

## 完整範例

### if / else if / else
```
🤔 a 📈 0 👇
    📢 "positive"
👆 🤷 a 📉 0 👇
    📢 "negative"
👆 🤷 👇
    📢 "zero"
👆
```

### for 迴圈
```
🎡 i 🚧 0 🚧 5 👇
    📢 i
👆
```

### while 迴圈
```
🔁 i 📉 10 👇
    📢 i
    i 🟰 i ➕ 1
👆
```

### 結構體
```
🏗️ Player 👇
    📝 name
    🔢 hp
    🔢 attack
👆

📦 p 🟰 🆕 Player
p ➡️ name 🟰 "Alice"
p ➡️ hp 🟰 100
📢 p ➡️ name
```

### 指標
```
🔢 a 🟰 42
📦 ptr 🟰 📍 a     # ptr = &a
📢 🎯 ptr         # print(*ptr) → 42
🎯 ptr 🟰 99      # *ptr = 99
```

```
📦 items 🟰 🆕 📋
items 🛒 "蘋果"
items 🛒 "香蕉"
📢 items
📢 📏 items
```
